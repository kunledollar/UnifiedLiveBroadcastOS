# UBOS v5.9.1 — Production-Safe Graphics and Text Rendering Foundation

This is the foundational graphics layer for UBOS. It does **not** perform real rendering. It establishes the deterministic, metadata-driven graphics model that every later graphics feature (templates, lower thirds, captions, branding, multi-format output, etc.) builds upon.
