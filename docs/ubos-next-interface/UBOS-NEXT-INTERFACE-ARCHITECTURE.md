# UBOS Next Interface Architecture

UBOS Next presents a Live Experience Operating System: Production Graph owns intent, Media Runtime executes media, and Social Fabric coordinates audience operations. This milestone mounts a presentation-only shell at control-room routes. It never imports, mounts, or invokes a runtime host.

## Boundary

The Workspace Manager selects a serializable `WorkspaceDefinition`; the Layout Engine is represented by each definition's `layout` and `responsive` policy. Deterministic demonstration fixtures remain client-local and only change visible copy. Program and Preview are CSS confidence illustrations with explicit `Media wiring pending` labels; they do not own a stream or media element.

## Future wiring

Every command holds `status: unwired`, a future domain, command ID, safety classification, and permission. The next milestone may introduce adapters at this declared boundary, not inside presentation components.
